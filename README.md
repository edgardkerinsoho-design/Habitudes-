# Calendrier

Cette version est autonome et ne dépend d’aucun service externe. Elle fonctionne avec un simple hébergement de fichiers statiques et conserve les activités et les coches dans le navigateur.

## Mise en ligne sur GitHub Pages

1. Crée un dépôt GitHub.
2. Copie le contenu de ce dossier à la racine du dépôt : `index.html`, `assets`, `fonts`, `icons`, `manifest.webmanifest` et `sw.js`.
3. Dans GitHub, ouvre **Settings → Pages**.
4. Choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
5. Ouvre l’adresse fournie par GitHub Pages.

Sur Android, ouvre cette adresse dans Chrome, puis choisis `⋮ → Ajouter à l’écran d’accueil` ou `Installer l’application`.
